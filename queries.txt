# Поисковые запросы к X. Одна строка — один запрос, # — комментарий.
#
# Синтаксис — операторы поиска самого X:
#   filter:links      только посты со ссылкой (без неё это не запуск продукта)
#   -filter:replies   не ответы в чужих ветках
#   min_faves:N       порог лайков НА МОМЕНТ ЗАПРОСА
#   lang:en           язык
#
# Про min_faves. Это грубый предфильтр, а не метрика отбора: он нужен
# только чтобы не тащить из X тысячи пустых постов. Настоящий отбор
# делает score.py по скорости и аномалии. Ставить его высоко — значит
# увидеть пост, когда он уже разошёлся, то есть опоздать. Держим низко.

"just launched" filter:links -filter:replies min_faves:20 lang:en
